# Project Instructions

Read this file before every task.

## About This Project

Night Reset is a personal bedtime-planning app that helps users notice when gaming or doomscrolling is delaying sleep and build a more consistent wind-down routine. See `PRD.md` for the product requirements.

## Stack

- App location: `project-1/`
- Next.js 16.3.5 (App Router), React 19.2.8, and TypeScript
- Tailwind CSS 4
- No component library is currently installed.
- Data: browser local storage for the user's bedtime plan and nightly check-ins; no database is currently configured.
- APIs: none are currently configured.
- Deployment target: Vercel

## Commands

Run these commands from `project-1/`:

- Run locally: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`

## Code Style

- Use TypeScript.
- Follow the existing Next.js App Router structure in `project-1/app/`.
- Put reusable components in `project-1/components/`, creating the directory when needed.
- Use Tailwind classes for styling and follow the existing global styles where appropriate.
- Use clear, descriptive names and keep page-level components easy to scan.

## Rules

- Don't add dependencies without asking first.
- Read `PRD.md` before adding a feature. Keep changes within its MVP scope.
- The MVP provides user-controlled reminders and bedtime tracking; do not claim that a browser app can reliably block other apps, websites, or games.
- Keep settings and check-ins on the user's device unless the product requirements are explicitly changed.
- Explain browser notification permission and delivery limitations; keep an in-app reminder available as an alternative.
- Never commit `.env.local`, API keys, or other secrets.
- Preserve `project-1/AGENTS.md`, which is generated by Next.js and contains framework-specific instructions.
